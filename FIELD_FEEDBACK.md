# FIELD FEEDBACK

Context: RC1 / Field Validation preparation.

## Field Truths Consolidated Today

1. Usability must be obvious in seconds.
- Field teams need clear next actions with minimal interpretation.

2. Operational memory is now a first-class requirement.
- The system must retain what happened, why, and what worked.

3. Role simulation before release is mandatory.
- Admin, Technician, Customer, Manager/Owner paths must all be validated with realistic daily sequences.

4. Simplicity beats feature volume.
- Clarity for non-technical users has higher business value than adding complexity.

5. Governance and delegation must evolve together.
- Career progression requires controlled access expansion and clear boundaries.

## Prioritized Validation Focus

### V1.0 Field Validation focus
- Living memory framing in all strategic documents.
- Operational knowledge preservation discipline.
- Visit-driven learning loop.
- Radical simplicity baseline.
- Role-based human simulations.
- Granular permissions by responsibility.
- Technician access to guides and intervention states.
- Branded report consistency.

### V1.0.1 focus
- Activation-link onboarding via WhatsApp / Email / SMS.
- Guided alert resolution.
- Manual invoice sending via WhatsApp / Email.
- Pending-tasks center.

### V1.1 focus
- Flexible contracts and seasonal pricing.
- Expense register monthly / annual.
- Structured progression path for technicians.
- Expansion of memory domains (pool/client/equipment depth).

### V2.0 and long-term focus
- Structured company knowledge governance (official/validated/rejected).
- Living technical manual and case library.
- Crystal Assistant / Crystal Companion.
- Voice layer and optional external AI analysis for image/video.
- Video memory strategy.
- Advanced Vision AI remains out of core for now.

## What This Means for Release Preparation

- No scope inflation in RC1.
- Field validation is about reliability, clarity, and memory discipline.
- Strategic roadmap is documented, but implementation remains phased by risk and business value.
