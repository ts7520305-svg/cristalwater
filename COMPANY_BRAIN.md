# COMPANY BRAIN

## Core Statement

Crystal OS is the living memory of Cristal Water.

The system exists to preserve operational knowledge, improve decisions, and make company execution repeatable.
Every visit must teach the company something useful.

## Memory Model

Crystal OS must preserve five memory layers:

1. Pool Memory
- Service history, chemistry trends, recurring incidents, preferred interventions.

2. Client Memory
- Communication preferences, contract context, payment behavior, recurring needs.

3. Equipment Memory
- Lifecycle, interventions, replacement history, recurring failure patterns.

4. Technician Memory
- Field execution quality, learning path, controlled access progression, incident handling patterns.

5. Company Memory
- Validated operational playbooks, rejected approaches, official best practices, and case library.

## Knowledge Governance

All captured knowledge must be classified as:

- Official best practices
- Validated knowledge
- Rejected knowledge
- Living technical manual entries
- Case library records

## Human-Centered Principle

Radical simplicity is mandatory:

- Any employee without technical training must understand what to do next.
- The system must reduce cognitive load, not increase it.
- Critical actions must be obvious and traceable.

## Release Discipline

Before each release:

- Run role-based human simulations (Admin, Technician, Customer, Manager/Owner).
- Verify that field execution is understandable and safe.
- Confirm that operational learning loops are preserved (visit -> record -> improvement).

## AI Boundary (Current Policy)

- Crystal Assistant / Crystal Companion are strategic directions for guided support.
- Voice interaction is a future usability layer.
- External AI analysis for images/videos is future optional.
- Advanced Vision AI stays outside the core system for now.

## Strategic Objective

Build a company that learns continuously from operations and turns experience into faster, safer, and more profitable execution.
